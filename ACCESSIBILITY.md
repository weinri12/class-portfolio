# Accessability Findings
- The first accessibility rating received from PageSpeed Insights was a score of 91. The color contrast for the navigation section was not a desirable contrast for the foreground letters of the navigation buttons.
- WebAIM.org was used to find a color combination that would work for the webpage.
- A meta tag for auto page refresh was also flagged as an issue and was deleted as it was foun to be unneccessary.
